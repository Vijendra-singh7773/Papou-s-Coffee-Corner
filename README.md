# Papou's Coffee Corner — Website

A responsive, modern one-page cafe website concept built with HTML, CSS and vanilla JavaScript. It uses the cafe photos supplied in the conversation and includes menu category filters, mobile navigation, scroll reveal effects, reviews, contact links and directions.

## Run locally

You can open `index.html` directly in a browser, or run a local static server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing
- Confirm menu items, prices, opening days/hours and contact details with the cafe.
- Replace or connect the Google Maps directions link with the cafe's exact map listing if needed.
- Add the cafe's official social links and update the review quotations/attributions as approved.
- Google Fonts are loaded online; system fallbacks are included.
